# The Illustrated Sherlock Holmes: Three Illustrated Editions

> These are some of my favorite works of fiction. And since they are in the public domain, I wanted to
> create fun illustrated versions of the books, and make them available to everyone for free.

I created these illustrated editions with **[Renderwolf](https://renderwolf.ai)** and **Claude**. Every
book pairs the full, unabridged public-domain text (from Project Gutenberg) with original artwork.

**📖 Read online → https://pawanp3.github.io/illustrated-sherlock-holmes/**

The complete Sherlock Holmes canon by **Sir Arthur Conan Doyle**, every original novel and
story collection, as newly **illustrated books** in **three distinct art styles**:

- **Watercolour & Ink**: a classic Victorian storybook look.
- **Mid-Century Modern**: a 1950s screen-print / poster look.
- **Casual Mobile**: a bright, candy-coloured mobile-game cartoon look.

Each edition comes in two formats:

- **Read online**: a page-flip HTML edition of each book (arrow keys / swipe / on-screen buttons).
- **Download EPUB**: a reflowable EPUB 3 for Kindle, Apple Books, Google Play Books, Calibre, and every modern e-reader.

Files are numbered in publication order, which is also the recommended reading order.

## Repository layout

```
index.html                              landing page (links every book, all three styles)
books/<style>/<nn>-<slug>/              style = watercolour | midcentury | casual-mobile
  index.html                            page-flip HTML edition (images linked from images/)
  images/                               the book's illustrations (JPEG)
  cover.jpg                             landing-page thumbnail
  <Title>.epub                          downloadable EPUB 3
```

## Reading the EPUBs

The `.epub` files are standard reflowable EPUB 3 with reader-resizable fonts. Open them in
Apple Books, Send-to-Kindle / Amazon KDP, Google Play Books, Calibre, or any modern e-reader.

## I need your help reviewing the images

I'll be candid: there are 2,087 AI-generated illustrations here, and I can't carefully vet every one on my
own. Some came out beautifully, and some are off (wrong anatomy, a character who doesn't look right, a
scene that misreads the text, or just a weak composition). **I'd genuinely appreciate help finding and
fixing the weak ones.**

If you spot an image that's below par, please
[open an issue](https://github.com/pawanp3/illustrated-sherlock-holmes/issues) with the book, the page,
and what looks wrong. Even just flagging it is a real help. If you'd like to go further, pull requests
with regenerated or improved images are very welcome. This is a free, public-domain project, and I'd love
for it to get better with the community's help.
