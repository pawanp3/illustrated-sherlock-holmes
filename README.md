# The Illustrated Sherlock Holmes — Complete Original Canon

The complete Sherlock Holmes canon by **Sir Arthur Conan Doyle** — every original novel and
story collection — as newly **illustrated books**, in two formats:

- **Read online** — a page-flip HTML edition of each book (arrow keys / swipe / on-screen buttons).
- **Download EPUB** — a reflowable EPUB 3 for Kindle, Apple Books, Google Play Books, Calibre, and every modern e-reader.

Every book contains the full, unabridged public-domain text (from Project Gutenberg) with
all-new watercolour-and-ink illustrations in a single consistent Victorian storybook style
across the whole library.

**📖 Read online:** _(GitHub Pages link — see the repo's Pages settings; it will be
`https://<username>.github.io/illustrated-sherlock-holmes/`)_

Files are numbered in publication order, which is also the recommended reading order.

## Repository layout

```
index.html                     landing page (links every book)
books/<nn>-<slug>/
  index.html                   page-flip HTML edition (illustrations linked from images/)
  images/                      the book's illustrations (JPEG)
  <Title>.epub                 downloadable EPUB 3
```

## Reading the EPUBs

The `.epub` files are standard reflowable EPUB 3 with reader-resizable fonts. Open them in
Apple Books, Send-to-Kindle / Amazon KDP, Google Play Books, Calibre, or any modern e-reader.
