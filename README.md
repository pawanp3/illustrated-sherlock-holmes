# The Illustrated Sherlock Holmes — Two Illustrated Editions

The complete Sherlock Holmes canon by **Sir Arthur Conan Doyle** — every original novel and
story collection — as newly **illustrated books**, now in **two distinct art styles**:

- **Watercolour & Ink** — a classic Victorian storybook look.
- **Mid-Century Modern** — a 1950s screen-print / poster look.

Each edition comes in two formats:

- **Read online** — a page-flip HTML edition of each book (arrow keys / swipe / on-screen buttons).
- **Download EPUB** — a reflowable EPUB 3 for Kindle, Apple Books, Google Play Books, Calibre, and every modern e-reader.

Every book contains the full, unabridged public-domain text (from Project Gutenberg).

**📖 Read online → https://pawanp3.github.io/illustrated-sherlock-holmes/**

Files are numbered in publication order, which is also the recommended reading order.
